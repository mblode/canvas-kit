# Installation

Canvas Kit is distributed as a [shadcn registry](https://ui.shadcn.com/docs/registry).
If you already have a React + Tailwind v4 app with the shadcn CLI configured,
adding a component is a single command.

## Prerequisites

- **React 19** and **Tailwind CSS v4**.
- A project initialised with `shadcn` (a `components.json` at the root). If you
  haven't, run `npx shadcn@latest init` first.

## Register the registry (once)

Add the `@canvas` namespace to your project so you can install items by name:

```bash
npx shadcn@latest registry add @canvas=https://blode.co/canvas-kit/r/{name}.json
```

Prefer not to register it? Every command below also works with the full URL,
e.g. `npx shadcn@latest add https://blode.co/canvas-kit/r/folder-card.json`.

## Install a component

## Manual setup

<Steps>
  <Step title="Add the theme variables">
    Canvas Kit reads its colours from `--canvas-*` CSS variables. Install the
    [`canvas-vars`](/docs/canvas-vars) theme (or copy the variables into your
    `globals.css`):

    <CommandTabs name="canvas-vars" />

  </Step>
  <Step title="Add the pieces you need">
    Browse the sidebar and install the [`canvas`](/docs/canvas) viewport plus any
    cards. Each registry item targets `components/canvas/` (the components) and
    `hooks/` (the hooks) by default.
  </Step>
  <Step title="Compose your canvas">
    Drop a `<Canvas>` somewhere full-bleed and place positioned children inside
    it. See [`canvas`](/docs/canvas) for the full example.
  </Step>
</Steps>

## Where files land

Components install to `components/canvas/`, hooks to `hooks/`, and the
`circular-progress` UI primitive to `components/ui/`. Adjust the targets in your
`components.json` aliases if your layout differs.
